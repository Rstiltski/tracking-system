# 🎯 What I Can Do - Weekly Page

## Purpose
View a 7-day summary of your tracking data. See trends, compare week-over-week progress, and get a comprehensive weekly overview.

---

## ✅ User Interactions

### Actions I Can Perform

| Action | How | Result |
|--------|-----|--------|
| **Navigate weeks** | Click ← → arrows | View different weeks |
| **View trends** | Scroll through page | See weekly trends |
| **Compare weeks** | Check week-over-week | Compare to previous week |

---

## 📊 Data Displayed

### Weekly Summary
| Metric | Description |
|--------|-------------|
| **Habits Completed** | Total habits completed this week |
| **Tasks Completed** | Total tasks completed this week |
| **Goals Progress** | Goals advanced this week |
| **XP Earned** | Total XP earned this week |

### Daily Breakdown
- **Monday - Sunday**: Each day's activities
- **Completion Rate**: Daily habit completion percentage
- **Activity Count**: Tasks, habits, goals per day

### Week-over-Week Comparison
- **Habit Change**: % change from last week
- **Task Change**: % change from last week
- **Streak Status**: Current streak information

### Trend Charts
- **Habit Trend**: 7-day habit completion chart
- **Task Trend**: 7-day task completion chart
- **Time Trend**: Time tracked per day

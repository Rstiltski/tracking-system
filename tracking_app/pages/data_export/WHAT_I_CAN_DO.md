# 🎯 What I Can Do - Data Export Page

## Purpose
Export your tracking data to various formats for backup, analysis, or migration to other systems.

---

## ✅ User Interactions

### Actions I Can Perform

| Action | How | Result |
|--------|-----|--------|
| **Select data type** | Check boxes | Choose what to export |
| **Select format** | Choose from dropdown | Set export format |
| **Set date range** | Pick dates | Filter data by date |
| **Export** | Click "Export" button | Download data file |

---

## 📊 Data Displayed

### Export Options
| Data Type | Description |
|-----------|-------------|
| **Habits** | All habit data and completions |
| **Tasks** | All tasks and history |
| **Goals** | All goals and progress |
| **Health** | Health entries |
| **Finances** | Financial transactions |
| **Time** | Time tracking entries |
| **Journal** | Journal entries |
| **Achievements** | Unlocked achievements |

### Export Formats
- **JSON**: Structured data format
- **CSV**: Spreadsheet compatible
- **PDF**: Printable report

---

## 🔗 Navigation

### Where I Can Go From Here
- **Data Import** (`data_import.py`) - Import data
- **Backup & Restore** (`backup_restore.py`) - Full backup

---

## ⚡ Quick Tips

1. **Regular Backups**: Export data monthly
2. **Multiple Formats**: Use JSON for backup, CSV for analysis
3. **Check Data**: Verify export contains all your data
4. **Store Safely**: Keep exports in a safe location

# 🎯 What I Can Do - Stacks Page

## Purpose
Create and manage habit stacks - groups of habits that you perform together. Build routines by chaining habits.

---

## ✅ User Interactions

### Actions I Can Perform

| Action | How | Result |
|--------|-----|--------|
| **Create stack** | Click "New Stack" | Stack creation form opens |
| **Add habit to stack** | Select habit, add to stack | Habit added to chain |
| **Remove habit** | Click remove on habit | Habit removed from stack |
| **Delete stack** | Click delete on stack | Stack removed |
| **Reorder habits** | Drag and drop | Change habit order |

---

## 📊 Data Displayed

### Stack Information
- **Stack Name**: What the stack is called
- **Habits**: Habits in the chain
- **Order**: Sequence of habits
- **Completion Rate**: How often you complete the full stack

### Stack Completion
- **Current Progress**: How many habits completed
- **Visual Chain**: See the habit sequence
- **Completion Status**: Per-habit status

## ⚡ Quick Tips

1. **Start Small**: Begin with 2-3 habits per stack
2. **Logical Order**: Order habits by when you do them
3. **Morning/Evening**: Create separate stacks for different times
4. **Build Chains**: Habit stacking builds strong routines

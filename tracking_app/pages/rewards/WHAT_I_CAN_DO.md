# 🎯 What I Can Do - Rewards Page

## Purpose
View and claim rewards you've earned through achievements and milestones. The reward store for your gamification progress.

---

## ✅ User Interactions

### Actions I Can Perform

| Action | How | Result |
|--------|-----|--------|
| **View rewards** | Browse reward list | See available rewards |
| **Claim reward** | Click "Claim" button | Reward unlocked |
| **Use reward** | Click "Use" on claimed | Apply reward benefit |

---

## 📊 Data Displayed

### Available Rewards
- **Reward Name**: What the reward is
- **Description**: What you get
- **Cost**: XP or achievement required
- **Status**: Available/Claimed/Used

### Reward Categories
| Category | Description |
|----------|-------------|
| **Themes** | UI customizations |
| **Icons** | Profile icons |
| **Badges** | Display badges |
| **Features** | Unlockable features |

### Your Balance
- **Current XP**: XP available to spend
- **Claimed Rewards**: Rewards you've unlocked
- **Used Rewards**: Rewards you've used

## ⚡ Quick Tips

1. **Save XP**: Save for bigger rewards

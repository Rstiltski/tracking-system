# 🎯 What I Can Do - Journal Page

## Purpose
Keep a personal journal to record thoughts, reflections, and daily experiences. Track your journaling habit and review past entries.

---

## ✅ User Interactions

### Actions I Can Perform

| Action | How | Result |
|--------|-----|--------|
| **Write entry** | Fill text area, click "Save" | Journal entry saved |
| **Edit entry** | Click edit on entry | Modify existing entry |
| **Delete entry** | Click delete on entry | Entry permanently removed |
| **Search entries** | Use search box | Find past entries |
| **Filter by date** | Use date picker | View entries from specific dates |

### Forms I Can Fill

**Journal Entry Form:**
- **Title**: Entry title (optional)
- **Content**: Your journal entry text
- **Date**: Entry date (defaults to today)
- **Tags**: Categorization tags (optional)
- **Mood**: How you're feeling (optional)

---

## 📊 Data Displayed

### Entry List
- **Date**: When entry was written
- **Title**: Entry title or "Untitled"
- **Preview**: First few lines of content
- **Tags**: Associated tags
- **Mood**: Mood indicator if set

### Statistics
- **Total Entries**: Number of journal entries
- **Writing Streak**: Consecutive days with entries
- **Most Common Tags**: Frequently used tags
- **Longest Entry**: Word count record

### Where I Can Go From Here
- **Dashboard** - Overview

## ⚡ Quick Tips

1. **Write Daily**: Build a journaling habit
2. **Use Tags**: Make entries searchable
3. **Be Honest**: Journal is private
4. **Review Past**: Read old entries for perspective

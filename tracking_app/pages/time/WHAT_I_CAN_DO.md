# 🎯 What I Can Do - Time Page

## Purpose
Track how you spend your time with a built-in timer and manual entry. Categorize activities and view daily/weekly summaries to understand your time usage patterns.

---

## ✅ User Interactions

### Actions I Can Perform

| Action | How | Result |
|--------|-----|--------|
| **Start timer** | Click "Start" button | Timer begins counting |
| **Stop timer** | Click "Stop" button | Timer stops, entry saved |
| **Reset timer** | Click "Reset" button | Timer reset to zero |
| **Add manual entry** | Fill manual entry form | Time entry recorded |
| **Delete entry** | Click delete on entry | Entry removed |

### Timer Controls
- **Start**: Begin tracking time
- **Stop**: Stop and save the time entry
- **Reset**: Clear current timer

### Forms I Can Fill

**Manual Entry Form:**
- **Activity**: What you were doing
- **Category**: Type of activity
- **Duration**: How long (hours:minutes)
- **Date**: When the activity occurred
- **Notes**: Optional details

---

## 📊 Data Displayed

### Timer Display
- **Current Time**: Running timer display
- **Status**: Running or Stopped
- **Current Activity**: What you're tracking

### Daily Summary
| Metric | Description |
|--------|-------------|
| **Total Time** | Hours tracked today |
| **Top Activity** | Most time spent on |
| **Categories** | Breakdown by category |

### Weekly Chart
- Visual representation of time spent
- Daily breakdown for the week
- Category color coding

### Time Entries List
- **Activity**: What was tracked
- **Category**: Activity category
- **Duration**: Time spent
- **Date**: When tracked

## ⚡ Quick Tips

1. **Use the Timer**: Real-time tracking is more accurate than manual entry
2. **Categorize**: Use consistent categories for better insights
3. **Track Everything**: Track all activities for complete picture
4. **Review Weekly**: Check weekly chart to identify time patterns
5. **Set Goals**: Use data to set time management goals

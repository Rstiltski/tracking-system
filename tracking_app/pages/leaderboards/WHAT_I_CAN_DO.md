# 🎯 What I Can Do - Leaderboards Page

## Purpose
View global and friend leaderboards. Compare your progress with others and see where you rank.

---

## ✅ User Interactions

### Actions I Can Perform

| Action | How | Result |
|--------|-----|--------|
| **View leaderboard** | Select leaderboard type | See rankings |
| **Filter by period** | Use period dropdown | Show specific time range |
| **Filter by category** | Use category dropdown | Show specific metrics |

---

## 📊 Data Displayed

### Leaderboard Types
| Type | Description |
|------|-------------|
| **Global** | All users ranking |
| **Friends** | Just your friends |
| **Weekly** | This week's top performers |
| **Monthly** | This month's top performers |

### Rankings
- **Rank**: Position on leaderboard
- **Username**: User's display name
- **Score/XP**: Ranking metric
- **Streak**: Current streak
- **Level**: User level

### Your Position
- **Current Rank**: Where you stand
- **XP**: Your total XP
- **Progress to Next**: How close to next rank

## 🔗 Navigation

### Where I Can Go From Here
- **Friends** (`friends.py`) - Add friends
- **Challenges** (`challenges.py`) - Join competitive challenges
- **Achievements** (`achievements.py`) - View achievements

## ⚡ Quick Tips

1. **Set Goals**: Aim for top 10 or top 100
2. **Weekly Reset**: Leaderboards reset weekly
3. **Compete with Friends**: Friend leaderboards are more personal
4. **Stay Consistent**: Consistency beats intensity

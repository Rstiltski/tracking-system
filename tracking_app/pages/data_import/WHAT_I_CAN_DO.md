# 🎯 What I Can Do - Data Import Page

## Purpose
Import data from exported files or other tracking systems. Restore your data or migrate from another app.

---

## ✅ User Interactions

### Actions I Can Perform

| Action | How | Result |
|--------|-----|--------|
| **Select file** | Click upload button | Choose file to import |
| **Preview data** | View preview section | See what will be imported |
| **Map fields** | Match fields to system | Align imported data |
| **Import** | Click "Import" button | Data added to system |

---

## 📊 Data Displayed

### Import Sources
- **Veryfyn Export**: Import from previous export
- **CSV Files**: Generic CSV import
- **JSON Files**: Structured JSON import

### Import Preview
- **Records Found**: Number of items to import
- **Fields Detected**: Data fields recognized
- **Warnings**: Any issues detected
- **Duplicates**: How duplicates will be handled

---

## 🔗 Navigation

### Where I Can Go From Here
- **Data Export** (`data_export.py`) - Export data
- **Backup & Restore** (`backup_restore.py`) - Full backup

---

## ⚡ Quick Tips

1. **Backup First**: Export current data before importing
2. **Check Preview**: Review data before confirming
3. **Handle Duplicates**: Decide how to handle conflicts
4. **Verify After**: Check imported data is correct

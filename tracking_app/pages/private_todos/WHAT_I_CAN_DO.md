# 🎯 What I Can Do - Private Todos Page

## Purpose
Keep private todos that are separate from your main task list. For personal or sensitive tasks you don't want mixed with regular tasks.

---

## ✅ User Interactions

### Actions I Can Perform

| Action | How | Result |
|--------|-----|--------|
| **Add private todo** | Fill form, click "Add" | Private todo created |
| **Complete todo** | Click checkbox | Todo marked complete |
| **Edit todo** | Click edit button | Modify todo |
| **Delete todo** | Click delete button | Todo removed |

---

## 📊 Data Displayed

### Private Todo List
- **Todo Text**: The todo content
- **Status**: Complete/Incomplete
- **Created Date**: When it was added
- **Priority**: High/Medium/Low (if set)

### Summary
- **Total**: All private todos
- **Completed**: Finished todos
- **Pending**: Still to do

---

## 🔗 Navigation

### Where I Can Go From Here
- **Tasks** (`tasks.py`) - Regular tasks

---

## ⚡ Quick Tips

1. **Keep It Private**: These don't sync with regular tasks
2. **Personal Notes**: Use for sensitive items
3. **Quick Capture**: Fast way to note private items
4. **Separate from Tasks**: Different from main task list

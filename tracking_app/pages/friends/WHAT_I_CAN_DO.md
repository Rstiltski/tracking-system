# 🎯 What I Can Do - Friends Page

## Purpose
Connect with friends, share progress, and motivate each other. The social hub for accountability and community.

---

## ✅ User Interactions

### Actions I Can Perform

| Action | How | Result |
|--------|-----|--------|
| **Add friend** | Enter friend code/username | Friend request sent |
| **Accept friend** | Click "Accept" on request | Friend added |
| **Remove friend** | Click "Remove" button | Friend removed |
| **View profile** | Click on friend name | See their public progress |
| **Send encouragement** | Click "Cheer" button | Send motivation to friend |

---

## 📊 Data Displayed

### Friends List
- **Username**: Friend's display name
- **Status**: Online/Offline
- **Streak**: Current streak count
- **Level**: User level
- **Recent Activity**: Latest achievements

### Friend Requests
- **Incoming**: Requests you've received
- **Outgoing**: Requests you've sent

### Activity Feed
- **Friend Achievements**: When friends unlock achievements
- **Streaks**: Friends' streak milestones
- **Challenges**: Friends joining/completing challenges

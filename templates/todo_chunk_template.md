# 🧩 Chunked Todo Template

**Purpose:** Break down complex work into manageable 1-3 task chunks with detailed explanations

---

## 📋 Chunk Metadata

| Field | Value |
|-------|-------|
| **Chunk ID** | `[Phase].[Subphase].[Chunk#]` |
| **Status** | `[ ] Planning` / `[-] In Progress` / `[x] Complete` |
| **Priority** | `High` / `Medium` / `Low` |
| **Effort** | `Small` (1-2 hrs) / `Medium` (3-5 hrs) / `Large` (6+ hrs) |
| **Dependencies** | List prerequisite chunks or files |
| **Target Completion** | Date or time estimate |

## 🎯 Chunk Overview

**Why:** Why this chunk matters in the broader context

**How:** High-level approach or methodology

**Success Criteria:** How we'll know this chunk is complete
